# 麦当劳到店真相（确定性校验器）

回答：**这张券，在这家店，此刻，到底能不能用**——三态结论 + 逐条依据。

## 命令

```bash
python -m src.cli stores  --city 城市 --keyword 地点 [--scenario pickup|drivethrough]
python -m src.cli coupons
python -m src.cli matrix  --city 城市 --keyword 地点     # 券 × 门店 真值矩阵
python -m src.cli verify  --coupon 券名片段 --store 门店编码
```

## 硬性表达规则

1. **只输出三态**：可以用 / 用不了 / 判不了。不许说「应该可以吧」。
2. **每条结论必须附依据**：列出命中的字段与值（如"门店不在适用清单内：门店=3450102，清单=2 项"）。
3. **缺字段 = 判不了**，不是"可以用"。特别是「适用门店清单」字段缺失时，必须说明。
4. **硬证据优先**：同时存在"已过期"和"字段缺失"时，判「用不了」。
5. 即使结论是「可以用」，结尾也要补一句：最终核销以门店实时结果为准。

## 不要做的事

- 不要替用户猜测未返回的字段。
- 不要在结论为 UNKNOWN 时建议用户直接下单。
- 不要使用「陷阱券」「注水券」等贬损性措辞。
